# Cloudflare 대체 구현

사용자 요청: 남은 문제를 수정하고 Cloudflare 백엔드로 오삼오삼을 대체한다. 상호 미정. 웹서비스부터 진행하며 기존 앱 배포와 실제 사용자 자료 삭제는 하지 않는다.

- 소스: 이 GitHub 저장소. 화면은 기존 React 컴포넌트, Worker는 `cloudflare/`.
- 기존 오삼오삼 Worker의 카카오·Google 로그인, 네이티브 인증, 이전 초대장 API는 유지한다. 새 홈페이지와 `/api/v2/`를 추가한다. 새 자료는 D1 `w2_` 테이블/R2 `w2/` 경로로 분리한다.
- 이전 초대장은 `/dashboard`에서 계속 관리한다. 신규 저장은 버전 충돌을 검사하고 명시적으로 게시한 스냅샷만 하객에게 공개한다.
- AI 예시는 둘러보기·편집용. 실제 게시 시 대표/갤러리 예시 사진 교체를 검사한다.
- 게시 취소 즉시 페이지·사진 접근 차단. 안정된 OG 사진 URL을 제공하되 캐시를 허용하지 않는다. 방명록은 소유자 승인 후 공개, RSVP 목록은 소유자만 조회한다.
- 사진은 서버에서 실제 디코딩·WebP 재인코딩. 사용자 100MB/신규 전체 1GB, 처리 동시 4건, 변환 100/일, R2 쓰기 2천/일·읽기 2만/일, 신규 API 1만/일. 계정 전체 요금 보장은 아니다. 유료 플랜 변경 없음.
- 저장량은 현존 사진 및 처리 예약의 합계. 실제 R2 삭제 성공 후 회수하며 실패 시 예약 유지·예약 작업 재시도. 미사용 사진은 24시간 뒤 정리한다.
- 새 자료의 만료는 행사일+30일. 작성 가능 행사일은 지난 30일~앞으로 2년. 실제 계정 삭제 요청을 즉시 조회에 반영하고 사진 정리 후 기존 삭제 작업이 진행한다.

완료 기준: TypeScript/lint/build, 실제 로컬 D1/R2·실제 이미지 디코더·workerd 검증, 모바일 편집/저장/게시 화면, 실제 Cloudflare D1/R2/사진 처리/두 계정 권한/게시 취소, 기존 자료 개수 보존, 공개 GitHub/Sites 연결과 비밀정보 검사.

현재: 웹 화면·D1·R2·Images 배포와 원격 합성 계정 검증 완료. 실제 Google 로그인 확인. 최종 보안 수정 배포와 기존 Sites 연결 결과는 current-state.md에서 관리한다. 기존 앱 교체는 이후로 확정됐다.
