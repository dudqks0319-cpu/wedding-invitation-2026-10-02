- 비용/악용: 운영 의존성/요금제/스위치/한도는 변경하지 않는다. 기존 인증 후 이미지 처리, 일일/전체 예산, 동시 처리·입력 크기·시간 제한, 중지 스위치를 유지한다. 운영 테스트는 두 합성 계정·사진 1장·초대장 1개로 한정하며 이 실행의 정확한 UUID/작업 ID만 정리한다. 실패 시 전체 업로드 스위치를 변경하지 않는다.
