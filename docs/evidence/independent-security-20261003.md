# 독립 청첩장 사이트 통합 보안 검사

2026-10-03. 이번 사이트·로그인 수정의 하나의 통합 gate. 수정 전 통합 결과는 `security-cloudflare-20261003.md`에 별도 보존한다.

- **비밀값·의존성**: 게시 입력과 격리 Worker dry-run의 177개 텍스트 경로에서 알려진 키·토큰 패턴 발견 0. 새 저장소 전체 audit 및 기존 Next 16.3.7 운영 런타임 production audit 취약점 0. [검사와 산출물 지문](independent-security-20261003.json). 비밀값을 소스·문서·화면에 넣지 않았으며 Sites/Cloudflare 서버 환경에만 저장한다. 이후 추가된 영수증은 ID·상태·집계만 포함하고 공급자 URL query·사용자 ID·쿠키는 제외했다.
- **인증·권한**: 새 사이트 origin을 고정하고 별도 HMAC 비밀값으로 검증한다. 구 사이트가 새 origin을 주장하거나 새 사이트가 기존 앱 API를 호출하는 경로를 차단한다. 일회용 확인값은 state·S256 challenge·호스트 쿠키·60초 만료·계정 삭제 상태를 검증한 뒤 원자적으로 소모한다. 재사용·변조·쿠키 없음·외부 이동 음성 검사가 통과했다. 해시 세션, HttpOnly/Secure 쿠키, same-origin 쓰기를 유지한다.
- **입력·출력**: 게이트웨이는 고정 upstream만 사용하고 caller identity/proxy 헤더를 제거한다. 미허용 공급자·중복 query·잘못된 인증값을 거부한다. 20초 upstream timeout과 상세정보 없는 503을 사용한다. 기존 사진 2MiB/40MP 입력 제한·재인코딩·메타데이터 제거·공개 DTO 제한을 유지한다.
- **개인정보·자료 보존**: 익명·다른 계정은 초안·RSVP·미사용 R2 사진을 조회하지 못한다. 인증 확인 중과 실패 시 비공개 화면을 가린다. 계정 변경·로그아웃 때 캐시와 초안을 정리하고 같은 계정 복귀 때 편집을 유지한다. 기존 계정 3명과 이전 자료 수가 점검 전후 동일하다. 정확한 점검용 ID만 정리하고 남은 레코드 0을 확인했다. 이메일 없음은 점검용 계정의 근거로 쓰지 않았다.
- **비용·악용**: auth-before-transform, D1 원자적 한도, 사진 4건 동시 처리·하루 100건·8초 Images timeout, 100MB 사용자/1GB 신규 전체 예산, API·업로드 중지 스위치를 유지한다. 인증 브리지는 기존 공개 쓰기 제한과 하루 전체 2천 건 제한을 추가 적용한다. 요금제와 기존 v1 예산을 바꾸지 않았다. 인증값·원문 IP·개인 식별자를 새 로그와 공개 증거에 남기지 않는다.
- **검증**: 로컬 Cloudflare 40개·인증 브리지 16개·게이트웨이 10개·세션 경계 6개 시나리오, 실제 Cloudflare 17개 PASS. TypeScript·lint·Next/Cloudflare 빌드·Wrangler dry-run 성공. 실제 Google 로그인·새로고침·로그아웃·다시 로그인 확인. 카카오는 계정 입력 화면까지 확인했다.

남은 관측은 카카오 최종 공급자 콜백, 실제 장기 보관·부하·Cloudflare 전체 청구 비용이다. 로컬/운영 합성 검사와 실제 공급자 브라우저 증거를 구분한다. App Store 준비 상태는 이번 웹 검사로 판단하지 않는다.
