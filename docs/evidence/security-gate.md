# 통합 보안 검사 — 2026-10-02

- **비밀 값**: 환경 예제의 키는 비어 있음. 서버 키는 서버 전용 모듈만 참조하고 클라이언트 번들에 포함하지 않음. 테스트의 `fixture-*`, `owner-token`은 격리 HTTP fixture 전용 가짜 값. Sites 단기 자격은 메모리·숨김 stdin으로만 사용.
- **인증·권한**: Supabase `/user` 검증, 사용자 소유권, 게시/만료 조건, 비공개 사진, 소유자 전용 RSVP, RLS와 클라이언트 쓰기 권한 철회. API 실패 경로는 통합 테스트로 확인. 실제 DB 정책 실행은 HOLD.
- **입출력**: 좁은 허용 값·길이·개수·날짜·사진 소유권 검사. 실제 JPG/PNG/WebP 디코딩·크기·화소 제한. React 텍스트 출력, 정적 예시 사진 allowlist, 임의 외부 사진·음악 URL 금지.
- **의존성**: 기존 lockfile 유지, 새 운영 패키지 추가 없음. npm audit 취약점 0개.
- **개인정보**: 방명록 해시 응답 제외, 참석 응답 소유자만 조회, 사진 메타데이터 제거, 초안 비공개, 게시 전 연락처·계좌·사진 공개 안내. 서버 응답에 내부 오류·개인 값 로깅 없음. 요청 식별값은 별도 키의 HMAC으로 저장.
- **남용 방지**: Origin/CSRF·PKCE flow·HttpOnly 세션, 영속 DB 한도·중복 키, 업로드 총량·동시 처리·시간 제한, 기능 중지 스위치. 한도 장애는 쓰기 차단. 자동 재시도 없음.
- **배포 경계**: Sites는 소유자 전용 local 모드 미리보기이고 외부 하객 공유 차단. Supabase 연결 전엔 원격 저장·로그인 성공을 표시하지 않음. 최종 결과는 `verification.json`.

Security Owner: 저장소 소유자 / 구현 Codex

Residual risks: 실제 Supabase 마이그레이션·RLS·OAuth·원격 API·운영 용량 관측 미확인. 원격 모드 활성화 전에 확인해야 함. 새 프로젝트·비용 선택 대기. 정적 Sites에는 Next API가 없으므로 원격 서버 배포가 별도로 필요함. 서명된 사진 URL은 공유 중지 후 최대 60초 남을 수 있음. 제3자 지도·글꼴·카카오 SDK는 해당 공급자 도메인에 네트워크 요청을 함.
