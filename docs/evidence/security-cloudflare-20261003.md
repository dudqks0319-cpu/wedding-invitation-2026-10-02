# Cloudflare 통합 보안 검사

2026-10-03. 담당 Codex. 하나의 통합 gate에서 발견사항을 수정하고 영향 검사를 다시 실행했다.

- 비밀정보: 공개 소스·최종 Worker/자산 경로 1,610개 검사, 토큰·키 패턴 발견 0. 비밀값은 기존 Cloudflare/Sites에 유지. 개인 브라우저·합성 세션·Wrangler SQL 작업 파일은 Git 제외.
- 인증/권한: 해시 세션·Secure/HttpOnly 쿠키, 소유자 전용 초안/RSVP/관리, 비공개 R2. 공개 스냅샷에 참조된 사진만 익명 조회. 두 계정·익명·계정 삭제 대기·공유 취소 차단 통과.
- 입력/출력: JSON 64KiB·사진 2MiB 제한, 실제 이미지 디코딩·메타데이터 제거, slug와 서버 소유 사진 검사, 계좌/갤러리 숨김은 공개 DTO에서도 제외. OG 문구 escape. Sites의 조작된 해시로 외부 도메인에 연결되지 않음을 검증.
- 동시성/재시도: revision 및 원자적 D1 batch, 멱등키/본문 HMAC, 만료가 별도 공개 스냅샷에 적용됨. 사진이 삭제되는 동안 저장하는 경쟁 조건은 서버 SQL 소유·ready 검사로 차단한다.
- 삭제/보관: 현존 사진 합계·진행 예약을 용량에 포함, 실제 R2 삭제 후 회수. 실패 예약 보존. 초대장/계정 삭제 때 중복 응답의 개인정보도 제거하도록 수정하고 다시 검사했다.
- 비용/악용: auth-before-transform, 사용자·클라이언트·전체 한도, 4건 동시 변환, 8초 Images 호출 제한, API/업로드 중지 스위치. IP는 HMAC 식별자로 저장. 원문 IP/토큰/비밀번호 로그 없음.
- 의존성: 새 저장소 전체 audit 취약점 0. 보존하려던 구형 런타임 audit에서 critical Next 16.3.4를 발견, 기존에 설치된 수정 버전 16.3.7로 격리 재빌드·배포. 해당 운영 사본 audit 취약점 0. [Next 공식 보안 권고](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j).
- 검증: 로컬 40개 및 실제 Cloudflare 13개 통과. 실제 Google 로그인 확인. TypeScript/lint/빌드 통과.

남은 관측: 실제 장기 만료/삭제 처리량·대규모 동시 부하·계정 청구 비용, 새 Kakao OAuth 종료까지의 브라우저 검증. 담당 운영자, 정식 서비스 확대 전 확인. 유료 요금제·결제·외부 메시지 발송·앱 교체를 이번 작업에서 시행하지 않았다.
