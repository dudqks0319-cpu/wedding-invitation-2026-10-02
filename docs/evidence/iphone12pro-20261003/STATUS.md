# iPhone 12 Pro 추가 검증

2026-10-03 KST. 실제 iPhone 12 Pro / iOS 26.6, 390×844pt. 대상은 독립 공개 사이트와 AI 예시 `/i/sample-blossom`이다. 시뮬레이터·로컬 Chromium 결과와 분리한다.

## 완료한 실제 기기 확인

- Safari 실사 AI 예시, 안내 문구, 연락처 열기/닫기, 갤러리 확대·다음 버튼·손가락 넘김 PASS. 실제 전화·문자는 보내지 않았다.
- 기본 Calendar 미리보기에 2027-04-17 12:30과 예시 장소가 표시됐다. ‘완료’로 닫았고 일정은 추가하지 않았다.
- 검색 `벚꽃` → 디자인 1개, 찜 추가 → Safari 새로고침 후 1개 유지, 찜 필터 선택과 해제 PASS. 테스트 찜을 제거해 처음 0개로 복원했다.
- 새 합성 편집 초안에서 사진 맞춤 선택·확대 슬라이더 1.00→1.50 반응 후 취소, 글꼴 Pretendard 표시 후 기본 글꼴 복원, 실제 주소 iframe의 공개 예시 주소 검색·선택·입력과 위경도 0 초기화 PASS.
- Safari 스크롤 관성 때문에 일부 터치가 빗나갔다. 사진 선택창을 열었다가 취소했으며 개인 사진은 열지 않았다. 새 검증용 로컬 초안의 예시 갤러리가 0장으로 바뀌었고 공개 예시 주소가 입력된 상태다. 서버 저장/게시와 기존 초안 편집은 실행하지 않았다.
- 사진 선택창 및 주소 선택 후 인증 상태 확인 화면이 일시 표시됐고 정상 복귀했다. 이를 OAuth 완료 증거로 쓰지 않는다.

## 발견·수정·배포·실기기 재검증

1. 고정 ‘디자인 목록’ 버튼이 이름·연락처·갤러리를 가렸다. 본문 탐색 영역으로 이동했다.
2. 작은 연락처·갤러리 닫기/이동 버튼을 44px 이상으로 확대하고 사진 선택 이름/선택 상태를 제공했다. 실제 iPhone에서 44~46pt, 내용 가림 제거, 버튼/스와이프 이동 PASS.
3. 14px 입력으로 Safari가 자동 확대돼 화면 오른쪽이 잘렸다. 검색·편집·하객 입력을 모바일 16px로 변경했다. 배포 후 실제 Safari 검색 필드 폭이 입력 전/중/후 350pt로 유지됐다.

소스: `68e4d0c`와 `28bf278c`. Worker `fa3f4c15-e5b2-4949-8394-7cfe2906d704`. TypeScript·lint·Next/Cloudflare build·Wrangler dry-run PASS. [검사 영수증](checks.json), [배포](deploy.json), [실기기 범위](physical-results.json). 320/390/430px overflow 0과 입력 16px는 별도 로컬 IAB 증거다.

백엔드/Worker entry/config/lockfile 지문은 기존 운영 배포와 동일하다. 이번 배포는 HTML 자산 1개다. 현재 Sites 경유 health 200/Cloudflare, 익명 목록·세션 401, 공개 예시 200 PASS. 기존 운영 20개 검사는 동일한 서버 모듈의 이전 증거이며 이번에 반복 수행한 검사로 표시하지 않는다. [읽기 전용 운영 확인](production-read-only.json), [보안](security.json).

## 남은 본인 인증 — HOLD

- iPhone 카카오톡 앱이 로그아웃 상태다. 기존 ‘나와의 채팅’ 링크 카드·카카오 인앱 청첩장은 앱 본인 로그인 후 확인해야 한다. 새 메시지는 보내지 않았다.
- 새 사이트 Google 버튼 → 계정 선택 → 저장된 패스키 Face ID까지 도착했다. 실제 생체 인증이 필요해 최종 공급자 콜백·새 사이트 세션 유지 검증은 대기한다. 기존 데스크톱 Google 완료와 별개다.
- Android와 네이티브 앱 교체는 이번 iPhone 웹 검증 범위 밖이다. release harness는 기존 웹 저장소에 native release-ledger/RELEASE_STATUS가 없어 ATTENTION을 반환했다. App Store 출시 완료로 해석하지 않는다.

개인 계정/패스키 및 최초 다른 앱의 화면 캡처는 ignored `cloudflare-private/iphone12pro/`에 있으며 공개 GitHub에서 제외한다. 동일 기기 다른 작업과의 초기 충돌은 그 작업 종료를 확인한 뒤 해소했다. 앱·일정·프로세스를 중단하지 않았다.
