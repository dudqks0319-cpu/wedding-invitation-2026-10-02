# 무료 첫 출시 소스 체크포인트 · 2026-10-08

이 저장소는 공개 개발 소스다. 현재 운영 사이트, 업로드된 TestFlight 빌드와 미배포 개발 소스를 구분한다. 이름은 아직 미정이고 화면의 임시 명칭은 ‘청첩장’이다.

## 현재 확인한 범위

- 운영 서버: 실제 Sites 게이트웨이와 Cloudflare Worker/D1/R2/Images에서 저장·권한·사진·공개·하객·만료·삭제24개 PASS. 합성 계정2개와 사진1장으로 검사했고 임시 자료 정리 및 기존 자료 집계 보존을 확인했다. 인증 공급자 실제 로그인은 이 합성 검사에 포함되지 않는다.
- 로컬 무료 후보: 결제 비활성, 구매 진입 제거, 제작자100명×사진31장 등록과 용량12그룹·기존 서버49검사, 웹/Worker/iOS 빌드 및 지정 시뮬레이터 실행의 기존 근거를 보존했다. 이는 운영100명 동시 부하·계정 비용 상한이나 실기기 전체 흐름의 증거가 아니다.
- Android: 독립 셸 및 서명 후보를 준비했다. 공개 저장소에는 서명키·개인 서명 설정·APK/AAB·Gradle 캐시를 포함하지 않는다. Play 등록/배포와 실제 로그인·공유 전체 흐름은 미완료다.

## 아직 출시 완료가 아닌 이유

새 후보에서의 실제 Apple/Google/카카오 로그인, 같은 후보의 휴대폰 제작·공유·수신·하객 응답·삭제, 운영자 정보와 개인정보·탈퇴·문의/신고의 운영 반영, Cloudflare 계정 합산 비용·엣지 방어, 의존성 보완, 최종 TestFlight/스토어 후보의 검증이 남아 있다. Apple 개발자 관리자 화면에는 접근할 수 있지만 이 앱의 Apple 로그인 capability는 비활성으로 확인됐다. 기능과 전용 키 연결을 완료한 것으로 표시하지 않는다.

첫 버전은 무료다. 내부 결제 관련 소스는 비활성 상태이며, 실제 상품·구매·복원·환불은 첫 출시 이후 범위다. 기존 오삼오삼의 데이터·계정·앱·키는 보존한다.

현재 공개 배포를 대상으로 데스크톱 Chrome에서 Google 실제 로그인·새 주소 복귀·새로고침 유지·로그아웃·재로그인을 추가 확인했습니다. 인증 시작/취소를 포함한8개 관측 결과는 [별도 브라우저 증거](evidence/launch-validation-20261008/oauth-browser.json)에 있습니다. 카카오 최종 인증과 Apple 로그인·실제 폰·새 후보의 전체 흐름은 미완료입니다.
