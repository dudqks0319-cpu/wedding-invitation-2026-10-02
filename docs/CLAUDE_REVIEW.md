검토 대상은 GitHub main `2066a31a1006f6026d915ad0aa7606c9bf610a0d`와 19종 모바일 표지 화면, 26장 실사 AI 사진 모음이다. Claude에서 읽기 전용 검토를 완료했다. Claude는 파일·계정·배포 설정을 변경하지 않았다.

## 판정과 확인 범위

- 디자인: 밝고 부드러운 국내 웨딩 스튜디오 톤이며, 사용자가 자기 사진을 넣은 모습을 예상하기 쉽다는 평가. 벚꽃 연서·아이보리 클래식·피치 필름·한옥의 봄·모던 매거진 등을 긍정적으로 평가했다. 하늘 편지·수채화 부케·미니멀 라인은 인물 사진을 떠올리기 상대적으로 약하다는 의견이다. 브랜드 디자인 복제 여부를 검증한 것은 아니다.
- 코드: Claude가 GitHub에서 최신 main을 읽고, 첨부한 83개 텍스트 파일과 내용 일치를 확인했다고 보고했다. 첨부 SHA256은 `c542fef03973ca759bc386c838c3102371e6e314e1ae8f74f49d320565589307`이다.
- 화면: 첨부한 실제 모바일 표지 모음과 저장소의 사진 모음을 확인했다. 개별 사진의 미세한 AI 흔적까지 판정하지는 못했다.
- 한계: Claude 환경의 프록시가 `*.chatgpt.site`를 403으로 차단하여 운영 URL의 직접 열람·조작은 수행하지 못했다. Codex는 별도로 인증 없는 Sites HTTP 200 및 공개 설정을 확인했다. Claude는 빌드·통합 테스트·실제 DB 테스트를 재실행하지 않았다.
- 현재 공개 사이트는 브라우저에만 저장하는 정적 미리보기다. 실제 Next API·Supabase·공급자 로그인·하객 공유는 미연결이다. 아래 원격 기능 관련 지적은 운영 백엔드 연결 전에 해결해야 할 사항이며 현재 Sites에서 발생했다고 주장하지 않는다.

## 추가 지적과 미확인 항목

Claude의 P3 의견: 없는 주소의 비로그인 응답이 로그인 안내로 바뀜, 원격 저장에서 허용하지 않는 배경음악 입력란, 수정 중 주소 변경 시 별도 청첩장 생성, 직접 선언하지 않은 `sharp` 의존성, 일부 한국어 조사, 중복 방지 레코드의 비밀번호 포함 payload 해시를 검토할 필요가 있다. 설치 환경별 실패나 비밀번호 역산은 실제로 시험하지 않았다.

후속 점검에서 Codex가 실제 PostgREST14.3/PostgreSQL17에 소스와 동일한 표지·갤러리 OR 필터를 실행해 HTTP200 및 예상 참조/미참조 결과를 확인했다. 실제 Supabase Cloud의 설정·사진 바이트 저장·60초 서명 URL과 카카오 캐시는 여전히 미검증이다. 기존 28개 HTTP fixture 검사는 실제 Supabase SQL·RLS·공급자 로그인을 증명하지 않는다.

## 후속 실행 증거

점검 소스는 `147f0cef3a6462e1e903a3335967fa19f71cf7e5`이며 앱 코드 변경 없이 실행했다. [백엔드 점검 보고서](BACKEND_CHECK_20261003.md)에 28개 HTTP fixture, 실제 SQL/RLS와 REST11개, 실제 브라우저 재현 및 운영 한계를 기록했다. 실제 로컬 화면2장과 보고서를 같은 Claude 대화에 전달하고 후속 검토를 완료했다.

Claude는 공개 main을 읽어 이전 검토 이후 앱·SQL·테스트·패키지 변경 없이 문서6개만 달라졌다고 확인했다. 첨부된 디자인 화면은 실제 판매 청첩장처럼 자연스럽다고 평가했고, 초안 충돌 화면과 기존 코드 경로의 일치를 확인했다. Sites403은 자신의 작업 환경 프록시 제한이며 사이트 접속 불가 판정이 아니라고 정정했다. 공개 소스의 비밀값 검사에서는 실제 키를 발견하지 않았다고 보고했다.

후속 판정은 **디자인·편집 미리보기는 완성됐지만 실제 하객 서비스 출시는 아직 이르다**다. 요청 한도·페이지 오류(P1), 초안 충돌·익명 공개 목록·AI 예시 사진·누적 저장량과 전역 잠금(P2)을 남은 출시 문제로 제시했다. 로컬 사진 OR 필터의 미확인은 해소됐다고 판단했다.

Claude는 SQL·REST·API를 직접 재실행하지 않았다. 검토 당시 새 원본 로그·JSON은 GitHub에 아직 업로드되지 않아 첨부 보고서를 기준으로 실행 결과를 평가했다. 해당 원본 증거는 이 후속 기록과 함께 공개 저장소에 올린다. 화면과 코드 직접 확인, Codex의 실행 증거, 실제 클라우드 미검증을 구분한다. [후속 검토 요약](evidence/claude-backend-followup-summary.json).

긍정 평가: 소유권 조건에 따른 변경·삭제·게시, PKCE/state 및 HttpOnly 로그인 쿠키, 쓰기 Origin 검사, 사진 실제 디코딩·화소 제한·EXIF 제거·소유권 검사, 소유자 전용 RSVP, 방명록 scrypt 해시, 직접 DB 쓰기 제한, 브라우저 저장 안내와 공유 비활성 동작의 일치.
