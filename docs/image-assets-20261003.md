# 웨딩 사진 및 소개 이미지

2026-10-03 사용자 요청에 따라 실사 AI 샘플 사진 2종을 새로 생성했다. 등장인물은 가상의 성인 커플이며 사용자의 실제 사진이 아니다.

- `public/photos/wedding-blossom-v2.webp`: 봄 벚꽃 아래 웨딩 화보. 밝은 베이지 예복, 아이보리 드레스, 자연스러운 표정·피부·손, 부드러운 필름 색감. 모바일 아치 표지에서도 두 얼굴이 보이도록 허리 위 구도.
- `public/photos/wedding-classic-v2.webp`: 같은 분위기의 성인 커플을 단정한 클래식 스튜디오 화보로 표현. 검은 턱시도, 아이보리 드레스·베일, 은은한 자연광과 절제된 배경.

생성은 내장 imagegen으로 진행했고 결과를 직접 확인했다. 기존 sharp로 WebP 포맷만 변환했다. 기존 원본 사진은 보존했다. 두 템플릿과 실제 사진 교체 예시, 소개페이지에서 새 사진을 참조한다.

Claude Code Opus (`claude-opus-5-5`)에 공개 기능 설명만 전달해 소개페이지와 세로 마케팅 구성 HTML 3개를 받았다. 도구 접근과 MCP를 끈 단일 실행이며 저장소, Apple 계정 자료, 실제 사용자 스크린샷을 전달하지 않았다. Codex가 실제 로컬 웹 화면 3개와 iOS 시뮬레이터 홈 화면을 직접 캡처해 삽입하고 문구·정적 경로·CSP를 검토했다.

- 공개 페이지: `/app-intro/index.html`
- 구성 소스: `/app-intro/promo-01.html`부터 `promo-03.html`
- JPG 결과: `/app-intro/promo-01.jpg`부터 `promo-03.jpg`, 각 1242×2688
- 실제 화면 PNG: `/app-intro/screenshots/` (로컬 예시 화면 및 iPhone 17 시뮬레이터)

이 이미지는 마케팅 초안이다. TestFlight 설치, 실제 iPhone 사용, App Store 출시, 실제 카카오톡 발송을 증명하는 자료는 아니다. 웹 캡처에는 로컬 미리보기 표시가 그대로 남아 있으며 개인 자료를 저장하거나 게시하지 않았다.
